# Пример за SQL Builder

Пример на TypeScript, демонстриращ SQL таг функции с SQLite база данни.

## Настройка

Инсталиране на зависимости:

```bash
npm install
```

## Изпълнение

Изпълнение на примера:

```bash
npm start
```

Или с автоматично презареждане по време на разработка:

```bash
npm run dev
```

## Компилиране

Компилиране на TypeScript в JavaScript:

```bash
npm run build
```

## Функции

- **SQL Таг Функция**: Безопасно изграждане на SQL заявки с помощта на шаблонни литерали
- **Параметризирани Заявки**: Автоматична защита срещу SQL инжекция
- **TypeScript Типове**: Пълна типова безопасност за операции с база данни
- **База данни с Тривита**: Пример с 10 тривиални въпроса в множество категории
- **CRUD Операции**: Примери за Създаване, Четене, Обновяване, Изтриване
- **Разширени Заявки**: Филтриране, търсене, групиране и статистики

## Примерни Заявки

Демонстрацията включва:

- Създаване на таблици
- Вмъкване на тривиални въпроси
- Филтриране по категория и трудност
- Пълнотекстово търсене с LIKE
- Групиране и броене
- Операции за обновяване и изтриване
