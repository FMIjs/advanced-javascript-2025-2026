# SQL Builder Example

TypeScript example demonstrating SQL tag functions with SQLite database.

## Setup

Install dependencies:
```bash
npm install
```

## Run

Execute the example:
```bash
npm start
```

Or with auto-reload during development:
```bash
npm run dev
```

## Build

Compile TypeScript to JavaScript:
```bash
npm run build
```

## Features

- **SQL Tag Function**: Safe SQL query building using template literals
- **Parameterized Queries**: Automatic protection against SQL injection
- **TypeScript Types**: Full type safety for database operations
- **Trivia Database**: Example with 10 trivia questions across multiple categories
- **CRUD Operations**: Create, Read, Update, Delete examples
- **Advanced Queries**: Filtering, searching, grouping, and statistics

## Example Queries

The demo includes:
- Creating tables
- Inserting trivia questions
- Filtering by category and difficulty
- Full-text search with LIKE
- Grouping and counting
- Update and delete operations
